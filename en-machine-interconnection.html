What we can integrate

If it has an interface, it can be connected.

Three routes, depending on what the system offers.

01

Public APIs

Full integration: read, write, events and notifications, with the service's official credentials.

02

Web interfaces without public APIs

If a service is used from a browser, we automate the same calls its web panel makes, within the service's terms of use.

03

Serial and Modbus

For devices without a network or with industrial protocols, a small bridge program reads the serial or Modbus port and delivers data to your systems.

FAQ

Answers before you ask.

Is interconnection needed for Italian Industry 4.0 incentives?

The 2026–2028 super-depreciation requires the asset to be interconnected with the company information system or supply network. We build the connection and document it; the final assessment is up to your appraiser.

Do I need to change my business software?

No. Machine data goes into a dedicated application and, where needed, is passed to the software you already use.

Do you modify the machine program?

No. We only read and write through the interfaces provided by the manufacturer.

Which machines does it work with?

We have already connected SCM machines with Maestro Active and Essetre/Tecnoessetre. For other brands we check interfaces and protocols before any quote.

What if the machine has no API?

It can still be connected: through the supervisor's web interface, if available, or with a bridge program reading the serial or Modbus port.

Do you do the wiring?

Wiring, lines and electrical panels are installed by licensed electricians under Italian law (DM 37/08), whom we work with. We take care of devices, configuration, software and data.
