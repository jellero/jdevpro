What I can integrate

If it has an interface, it can be connected.

Three routes, depending on what the system offers.

01

Public APIs

Full integration: read, write, events and webhooks, with the service's official credentials.

02

Web interfaces without public APIs

If a service is used from a browser, I automate the same calls its web panel makes, within the service's terms of use.

03

Serial and Modbus

For devices without a network or with industrial protocols, a middleware reads RS-485/RS-232 and Modbus RTU/TCP and delivers data via API or MQTT.

FAQ

Answers before you ask.

Do you connect Amazon, eBay and other marketplaces?

Yes. I have built integrations with SellRapido, IBS, Temu and GLS; Amazon, eBay, Shopify and other marketplaces with public APIs connect the same way: offers, prices, stock, orders and shipments.

Can a service without public APIs be integrated?

Yes. If it is used from a browser, I automate the same calls its web panel makes, after checking the terms of use. For devices and machines without a network I use a serial or Modbus middleware.

What happens if a system is down?

Data waits in a queue and is sent when the system is back, without duplicates.

Do you work remotely?

Yes. For software integrations I work almost always remotely, with agreed and logged access.
