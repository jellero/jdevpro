What we can integrate

If it has an interface, it can be connected.

Three routes, depending on what the system offers.

01

Public APIs

Full integration: read, write, events and notifications, with the service's official credentials.

02

Web interfaces without public APIs

If a service is used from a browser, we automate the same calls its web panel makes, within the service's terms of use.

03

Serial and Modbus

For devices without a network or with industrial protocols, a small bridge program reads the serial or Modbus port and delivers data to your systems.

FAQ

Answers before you ask.

Do you connect Amazon, eBay and other marketplaces?

Yes. We have built connections with SellRapido, IBS, Temu and GLS; Amazon, eBay, Shopify and other marketplaces with public APIs connect the same way.

Can a service without public APIs be integrated?

Yes. If it is used from a browser, we automate the same calls its web panel makes, after checking the terms of use. For devices and machines without a network we use a serial or Modbus bridge.

What happens if a system is down?

Data waits and is sent when the system is back, without duplicates.

Do you work remotely?

Yes. For integrations we work almost always remotely, with agreed and logged access.
