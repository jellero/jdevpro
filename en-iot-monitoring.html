What I can integrate

If it has an interface, it can be connected.

Three routes, depending on what the system offers.

01

Public APIs

Full integration: read, write, events and webhooks, with the service's official credentials.

02

Web interfaces without public APIs

If a service is used from a browser, I automate the same calls its web panel makes, within the service's terms of use.

03

Serial and Modbus

For devices without a network or with industrial protocols, a middleware reads RS-485/RS-232 and Modbus RTU/TCP and delivers data via API or MQTT.

FAQ

Answers before you ask.

Does it work without Internet?

Yes. Data is stored locally and sent when the connection is back.

Which brands can be integrated?

All those with public APIs, such as Tuya, Aqara, Honeywell, Shelly, Netatmo, Philips Hue, Fronius, SMA or SolarEdge. If a device only has an app or web panel, I automate its calls; if it only has a serial or Modbus port, I use a middleware.

Is the data secure?

Communication is encrypted and devices sit on networks separated from the office network.

Who looks after the system after installation?

I do, with a plan covering remote monitoring, updates and support.
